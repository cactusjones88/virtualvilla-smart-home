# 🏠 VirtualVilla Smart Home System

A multi-room smart home system with motion-activated lighting automation.

## ✨ Features

- ✅ Motion-activated lighting
- ✅ Multi-room support
- ✅ Double-click motion detection (desktop)
- ✅ Phone shake detection (mobile)
- ✅ Manual controls and debug interface
- ✅ Real-time automation execution

## 🚀 Quick Start

1. Open `index.html` in a web browser
2. The system auto-creates living room devices
3. Test with:
   - Double-click anywhere on page
   - Click "Test Motion" button
   - Shake your phone (mobile)

## 🛠️ Technology

- Pure JavaScript (ES6+)
- WebSocket connectivity
- Device Motion API
- Event-driven architecture
